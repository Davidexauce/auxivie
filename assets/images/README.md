# Assets Images

Placez ici les images de l'application, notamment :

## Logo
- `logo.png` ou `logo.svg` : Logo principal d'Auxivie (fond vert avec le texte blanc)
  - Format recommandé : PNG transparent ou SVG
  - Tailles recommandées :
    - `logo.png` : Version haute résolution (1024x1024 ou plus)
    - `logo_small.png` : Version pour l'écran de démarrage (200x200)
    - `logo_appbar.png` : Version pour la barre d'application (64x64)
