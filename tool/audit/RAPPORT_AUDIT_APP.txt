4. PARCOURS UTILISATEUR (SYNTHÈSE)
----------------------------------

A) Premier lancement / retour
   ConsentGate → si pas de consentement stocké → ConsentScreen → puis enfant (Splash).
   Splash → AuthViewModel.init() (≤2s) → Home si token+user persistés, sinon Choice.

B) Famille (client)
   Choice → Connexion Famille ou Inscrivez-vous → profil Famille.
   Home : onglets Accueil | Recherche | Messages | Planning | Profil.
   • Recherche : liste pros → fiche ProfessionalDetail → réservation / message / Signaler.
   • Messages : liste conversations → ChatScreen (messages via API, MessageValidator anti-coordonnées).
   • Planning : réservations → détail → paiement Stripe si proposé → signalement problème.
   • Profil : infos perso, documents (caméra/galerie/fichiers), légal, consentements, suppression compte.

C) Professionnel
   Choice → Connexion Professionnel ou inscription pro.
   Home : Accueil | Tableau | Messages | Planning | Profil.
   • Tableau : stats / réservations / badges (API).
   • Planning / Messages / Profil : logique équivalente côté métier pro.

5. ÉTAT PAR FONCTIONNALITÉ
--------------------------

| Domaine          | Intégration      | Commentaire |
|------------------|------------------|-------------|
| Auth login/register | API | Token + user JSON prefs ; erreurs remontées au UI. |
| Suppression compte | API DELETE /users/:id | Dépend du backend ; sinon erreur UI. |
| Réservations CRUD | API principalement | Voir risque « deleteReservation » ci-dessous. |
| Paiement Stripe | API create-intent + PaymentSheet | Dépend backend / clés ; double init possible main vs PaymentService (voir note). |
| Messagerie | API + validation locale | Bloque partage tel/email/etc. (MessageValidator). |
| Signalements | API (modal / écran / réservation) | Parcours multiples cohérents. |
| Consentements | ConsentService local | Ré-affichage via Profil → Gérer mes consentements. |
| Maintenance | Settings API | Peut verrouiller toute l’app si activé. |
| RIB (Profil) | NON persisté | Écran simule succès — voir dette §6. |
| SQLite DatabaseService | NON utilisé | Code mort côté app actuelle (aucune import lib/). |
